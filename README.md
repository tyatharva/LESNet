# LESNet
Code from the paper "Next-Hour Lake-Effect Quantitative Precipitation Forecasts over the Great Lakes with Deep Learning."
Each pix2pix_? folder is essentially of fork of [pix2pix](https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix) with heavy modifications.
Run this in a conda environment using env.yml.
Paper avaible at https://doi.org/10.1175/AIES-D-25-0009.1
