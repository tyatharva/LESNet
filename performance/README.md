To use it, you select a lake, select a date and hour (shaded dates have lake-effect, color-coded by how the data was used with the model), and then run the model, which can take a bit since it's running on low-power CPUs. Then, you can select what variables (ex. QPE_target as target, TMP_925mb as 925 mb temperature) to display on each of the four panels. The top right of each panel has the mean absolute error of the visualized variable compared to QPE_target. Once data is generated, you can select it from the "Available Data" section to avoid re-running the model.
